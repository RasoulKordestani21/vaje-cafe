Project Overview

Vaje Cafe یک سیستم end-to-end برای مدیریت کافه است که سه جهان مجزا دارد: مشتری (وب‌سایت عمومی)، ادمین (داشبورد مدیریت) و پرسنل (پنل کارکنان). تمام داده‌ها در SQLite ذخیره می‌شود و API از Next.js App Router تامین می‌شود.

Customer Flow

مسیر کاربر عادی از ورود به سایت تا ثبت سفارش

1
Visit Homepage کاربر وارد / می‌شود — بنرها، استوری‌ها، نظرات و hero section نمایش داده می‌شود
2
Browse Stories & Menu کلیک روی StoryAvatar → StoryViewer | رفتن به /menu → دریافت آیتم‌ها از GET /api/menu
3
Customer Login (Optional) /customer/login → شماره موبایل → OTP → customer_auth_token cookie → CustomerContext
4
Place Order انتخاب آیتم‌ها → POST /api/orders → ثبت در orders + order_items + order_status_history
5
Profile & Loyalty /profile → /api/customer/profile | امتیاز وفاداری از /api/loyalty/balance

Admin Flow

مسیر مدیر از login تا مدیریت کامل کافه

1
Login /login → POST /api/auth/login → bcrypt verify → session in DB → auth_token cookie (5h)
2
Auth Guard middleware.ts checks cookie → MenuContext validates via GET /api/auth/validate → sessionStorage vaje_auth
3
Dashboard Access /dashboard → role-based tabs (admin vs super_admin vs staff) → render tab content
4
Manage Operations منو، سفارشات، موجودی، گزارش‌ها — هر tab component/API مخصوص خود را دارد
5
Logout POST /api/auth/logout → clear session + cookie + sessionStorage → redirect /login

API Auth Pattern (Dashboard)

تمام APIهای محافظت‌شده از ensureAdmin(request) در src/lib/auth.ts استفاده می‌کنند:

// src/lib/auth.ts pattern export function ensureAdmin(request: NextRequest) { const token = request.headers.get("x-access-token") || request.cookies.get("auth_token")?.value; if (!token || !validateSession(token)) { return NextResponse.json({ error: "Unauthorized" }, { status: 401 }); } return null; // null = authorized }

Getting Started

1
Install & Configure npm install → copy .env.example to .env.local → configure SMTP
2
Initialize Database node scripts/init_databases.js → node scripts/create_super_admin.js
3
Start Dev Server npm run dev → open http://localhost:3002
4
Login & Explore Admin: /login | Public site: / | Menu: /menu | Dashboard: /dashboard
